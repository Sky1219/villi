# Close the ASK loop, impact view, caregiver role, cuts

1. Questions get a status (open -> asked -> answered): "I asked this" tap; "Log what they said" writes the care-team answer with `resultingChange` (formulation_changed | dose_monitored | no_change | pending), updatable while pending.
2. `/impact` "Is Villi working?": one query, flags raised / questions asked / answers logged / formulation changes / rated useful, stratified by anatomy, real vs demo counts.
3. Caregiver profiles record who they care for (parent / partner / child / other family member); home, log and sheet say so; the sheet is written in the third person so either person can hand it over; the agent addresses the caregiver.
4. Cuts: language step and selector hidden (English only), open questions refused at `answers.start`, food-package photos refused. (No 90-day guide exists.)
5. "Was this useful?" tap on each answer.
6. Tests, tsc, browser check at 320px, DEMO.md / README.
